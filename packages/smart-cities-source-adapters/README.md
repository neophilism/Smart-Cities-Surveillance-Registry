# Smart Cities source adapters

Provider-specific public-source adapters for the Smart Cities Surveillance
Registry.

This package is intentionally downstream of
`@civic-registry/source-adapters`.

It contains Smart Cities/provider knowledge for Socrata, ArcGIS FeatureServer,
CKAN, procurement exports, and official HTML/document catalogs while relying on
the engine package for hardened HTTP retrieval and deterministic adapter-run
semantics.

See [Smart Cities official-source adapters](../../docs/SMART-CITIES-SOURCE-ADAPTERS.md).
